specjutsu-bench

A reproducible token benchmark for spec-driven development workflows. The same three tasks run on the same small TypeScript app with each setup, and every byte the workflow puts into the agent's context is counted. Every tool is pinned, and every step cites the doc that prescribes it.

    How to read this

    Context bytes are every file loaded or read and the output of every command run. Output bytes are the files the agent writes, roughly equal by design. Only specjutsu's CLI runs; where a rival's docs prescribe its own CLI the step is left out, so the rivals' totals are lower bounds. The method, the fixture and every step script are in the repository; if a step misreads a tool's docs, open an issue or a pull request that cites the doc.

    Generated from results.json, the results committed on main and checked by CI. Benchmarking specjutsu, the quality gate for AI-generated code.
